Parámetros del sistema

Configurar umbrales de alerta

Los umbrales definen cuándo cambia el estado de alerta. Se validan en el navegador (rangos y coherencia) y se guardan en la persistencia seleccionada.

Umbrales (en °C)

Cómo se aplican

  • Frío: temperatura menor al umbral de frío.
  • Normal: entre el umbral de frío y el de precaución.
  • Precaución: desde el umbral de precaución.
  • Calor: desde el umbral de calor.
  • Crítico: desde el umbral crítico.

La regla exige umbrales crecientes: frío < precaución < calor < crítico. Si no se cumple, el formulario rechaza el guardado y muestra el error.

Sobre esta demo

Demo estática vs. aplicación MVC

Esta página es una réplica estática de la interfaz: toda la lógica corre en el navegador y no hay servidor. La solución oficial del desafío es la aplicación ASP.NET Core MVC (Vistas → Controladores → Modelo/Servicios → Firebase) disponible en el repositorio y desplegada en Azure App Service.

Simulación

Un temporizador del navegador genera lecturas cada 8 s (random walk) y calcula el estado con las mismas reglas que la app.

Persistencia

LocalStorage por defecto; con la URL de Firebase configurada en demo/demo.js usa Realtime Database vía REST.

Código fuente

El proyecto MVC completo está en el repositorio de GitHub.
